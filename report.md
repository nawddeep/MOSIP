## Decisions made
- Scope limited to MiniFASNet only. Export keeps raw logits; softmax + fusion in caller code (mirrors upstream).
- `real_score` = mean class-1 prob (threshold this). Canonical integer resize (not cv2.resize), identical in Python & Java.
- Exact-2x downscale: generic OpenCV switches to INTER_AREA; we do not (rare; within tolerance) — documented.
- Eval: presentation = file; APCER reported = max over species; failures to process excluded and counted separately.

## Findings (code-backed; upstream paths relative to minifasnet-study/Silent-Face-Anti-Spoofing)
- data_io/functional.py: to_tensor -> `img.float()` (div(255) commented out) => raw 0..255, CHW, BGR.
- generate_patches.py: scale clamp, shift-inside, int() truncation, inclusive slice, cv2.resize bilinear.
- anti_spoof_predict.py: softmax over 3 logits; detector = RetinaFace Caffe via cv2.dnn. test.py: sum softmax, 1 = real, score/2.
- train_main.py: loss 0.5 CE + 0.5 MSE(Fourier map); MultiFTNet always builds MiniFASNetV2SE (shipped = V2, V1SE) -> recipe mismatch.
- LICENSE Apache-2.0 (code). README: no weight license, no training-data statement.
- opencv-python 4.14 arm64 uses Carotene + KleidiCV HAL; cv2.resize differs +-1 px from the generic algorithm.
- Box definition matters: same print-attack video 0.075 (Haar box) vs 0.015 (RetinaFace box).
